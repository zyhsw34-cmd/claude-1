# 跑团桌面（单人 TRPG 网页）

一个自己玩的跑团网页：左边是角色卡，中间是地图、战斗和骰子，右边是 AI 主持人（DM）。
DM 用 DeepSeek 的 AI 扮演。没填密钥时是"演示模式"，DM 只会说几句固定台词，用来先看看界面。

整个网页只是几个普通文件：不用安装，也不用"编译"。

---

## 一、怎么打开

### 在自己电脑上

最简单的办法：直接双击 `trpg-table/index.html`，用浏览器打开。

如果要连 DeepSeek，更稳妥的办法是开一个"本地小网站"再访问（有的浏览器不让双击打开的网页连外网）：

```bash
cd trpg-table
python3 -m http.server 8000
```

然后浏览器打开 <http://localhost:8000>。关掉命令行窗口，网站就停了。

### 在云服务器上，用平板访问

第一次，在服务器上把代码下载下来：

```bash
git clone https://github.com/zyhsw34-cmd/claude-1.git
cd claude-1/trpg-table
python3 -m http.server 8000
```

之后每次：

```bash
cd claude-1
git pull                      # 先拿最新代码
cd trpg-table
python3 -m http.server 8000   # 启动
```

**平板怎么看到这个网页？** 推荐用 SSH 的"端口转发"，这样只有你自己能访问：

- 用电脑或平板的命令行连接服务器时，加上 `-L 8000:localhost:8000`：
  `ssh -L 8000:localhost:8000 你的用户名@服务器地址`
- 如果你用的是 Termius 之类的 SSH App，找"Port Forwarding / 端口转发"，
  本地端口填 8000，目标填 `localhost:8000`。
- 连上以后，在平板浏览器打开 <http://localhost:8000>。

> 不推荐直接开放服务器的 8000 端口给整个互联网。真要这么做，记得在云服务商的防火墙里只允许你自己的 IP。

## 二、两边换着改代码，怎么不打架

你有两个地方会让 Claude 改代码：**这台电脑**，和**平板 SSH 上去的云服务器**。
GitHub 上的 `claude-1` 仓库是唯一的"正本"，两边都只和它同步。

三条习惯：

1. **开工第一句**：先跟 Claude 说"先把最新代码拉下来"（就是 `git pull`）。
2. **收工最后一句**：跟 Claude 说"把改动提交并推上去"（就是 `git add`、`git commit`、`git push`）。没推上去的改动，另一边看不到。
3. **同一时间只在一边改。** 万一两边改了同一个地方，`git pull` 会报"冲突（conflict）"。别慌，跟 Claude 说"帮我解决冲突"，它会把两边的改动合在一起，不会丢东西。

有两样东西**不走 GitHub**，每台设备各管各的：

| 东西 | 存在哪 | 换设备时 |
| --- | --- | --- |
| DeepSeek 密钥 | 这台设备的浏览器里 | 在新设备的「设置」里再填一次 |
| 游戏存档 | 这台设备的浏览器里 | 点「导出存档」下载一个文件，到另一边点「导入存档」 |

密钥绝对不要写进代码文件里，否则会跟着仓库一起被上传。

## 三、连上 DeepSeek

1. 去 DeepSeek 开放平台申请一个 API 密钥（以 `sk-` 开头）。
2. 打开网页，点右上角「设置」，粘贴密钥，保存。右上角 DM 区的小圆点变绿就连上了。
3. 模型名默认是 `deepseek-flash`（便宜、快）。想要更强可以改成 `deepseek-v4-pro`。
   这两个名字来自 DeepSeek 官方文档（2026 年 11 月），以后官方改名了，直接在设置里改就行，不用动代码。
4. 「深度思考」默认关闭：关掉回复更快更省钱，打开后 DM 会先想一会儿再说话。

还没验证过：浏览器能不能直接连上 DeepSeek（有的网站不允许网页直接调用）。如果点发送后报错"连接 DM 失败"，
把报错原文告诉 Claude，它会加一个小的中转脚本。

## 四、想改外观或内容，改哪个文件

```
trpg-table/
├── index.html          页面上有哪些区块（骨架）
├── css/
│   ├── theme.css       颜色、字体、圆角 —— 换主题改这里
│   ├── layout.css      区块怎么摆放 —— 挪位置改这里
│   └── components.css  按钮、棋子、骰子等零件的样子
├── js/
│   ├── store.js        数据和存档
│   ├── dice.js         骰子区
│   ├── sheet.js        角色卡区
│   ├── board.js        地图区（拖棋子）
│   ├── combat.js       战斗区（先攻、回合、生命值）
│   ├── dm.js           DM 区（和 DeepSeek 聊天）
│   ├── settings.js     设置弹窗、导入导出
│   └── main.js         启动各个区块，也管主题列表
└── presets/
    └── default.js      剧本预设：规则、属性名、示例角色、地图、DM 的说明
```

几个常见改法：

- **加一个配色主题**：在 `css/theme.css` 里复制一整块 `[data-theme="starlight"] { … }`，改名改颜色，
  再在 `js/main.js` 的 `THEMES` 里加一行。顶栏的「主题」下拉框就会出现它。
- **挪区块位置**：改 `css/layout.css` 里的 `grid-template-areas`。那几行字就像一张平面图，
  比如把 `"sheet board board dm"` 改成 `"dm board board sheet"`，角色卡和 DM 就左右对调了。
- **做新剧本**：复制 `presets/default.js`，改个文件名和里面的 `id`、`name`，改属性、地图、DM 说明，
  然后在 `index.html` 底部照着加一行 `<script src="presets/你的文件.js"></script>`。在「设置」里就能选。

做同人剧本（比如《崩坏：星穹铁道》世界观）只用于自己本地玩，不要公开发布，也别把官方美术、音乐放进仓库。

## 五、怎么玩

- **聊天**：在 DM 区打字说你想做什么，Enter 发送。
- **DM 要你检定**：DM 的回复里会出现金色按钮，比如「洞察检定 · 难度 13」，点一下就自动投骰，结果发给 DM，DM 接着讲。
- **自己投骰**：骰子区点 d4～d100，或输入 `2d6+3` 这样的式子。勾着「结果告诉 DM」时，结果会记进聊天里，下次发言时 DM 能看到。
- **属性检定**：点角色卡上的属性方块，或者在骰子区选属性、填难度后点「检定」。规则是 d20 + 属性值 ≥ 难度就成功，骰出 20 大成功，骰出 1 大失败。
- **地图**：拖动棋子移动，点一下选中。「+ 同伴」「+ 敌人」加棋子，「移除选中」删掉。
- **战斗**：点「投先攻」给地图上每个棋子排顺序，「下一位」轮到下一个，每行的 −/+ 调生命值。你的生命值和角色卡同步。
